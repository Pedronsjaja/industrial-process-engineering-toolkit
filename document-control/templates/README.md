# Document templates

Use the existing [document register](../document-register.csv) to track ownership and revisions. Editable report templates live in [reports/templates](../../reports/templates/); they are maintained there to avoid duplicates.

Choose an [academic](../../reports/templates/academic-report-template.md), [technical](../../reports/templates/technical-report-template.md), [engineering analysis](../../reports/templates/engineering-analysis-template.md), or [test](../../reports/templates/test-report-template.md) template. Apply the [naming standard](../naming-standard.md), record the revision, and arrange review manually. No document approval or report-generation service is implemented.
