# Document control

Suggested filename: `PROJECT-TYPE-DESCRIPTION-REVISION-YYYY-MM-DD.ext`, for example `GAIA-REL-TesteServo-R02-2026-10-26.pdf`.

`automation/check_file_names.py` validates this pattern for files in a directory. It checks syntax only; it does not verify revision approval, document content, or metadata consistency.

See `naming-standard.md`, `revision-control.md`, and `document-register.csv`.
