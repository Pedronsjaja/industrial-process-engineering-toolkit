# Document naming standard

Use `PROJECT-TYPE-DESCRIPTION-REVISION-YYYY-MM-DD.ext`.

- PROJECT and TYPE: uppercase letters/numbers.
- DESCRIPTION: a concise token using letters/numbers.
- REVISION: `R` followed by at least two digits.
- DATE: issue date in ISO order.

Example: `GAIA-REL-TesteServo-R02-2026-10-26.pdf`. This repository's validator enforces filename shape only; define controlled vocabularies and approval rules locally.
