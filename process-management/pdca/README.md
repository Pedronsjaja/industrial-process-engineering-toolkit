# PDCA template

Use one record or worksheet per improvement cycle.

| Phase | Suggested fields |
|---|---|
| PLAN | problem, context, evidence, cause, current indicator, target, scope |
| DO | actions, owners, due dates, resources, implementation evidence |
| CHECK | post-change indicator, evidence, comparison period, deviations |
| ACT | standardization, lessons learned, residual risk, next action |

Targets and acceptance criteria are organization-defined. Preserve the source data used to evaluate results.
