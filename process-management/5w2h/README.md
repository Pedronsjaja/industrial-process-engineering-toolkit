# 5W2H action planning

Document each action with What, Why, Where, When, Who, How, and How much. The example register at `examples/5s-workshop-case/actions.csv` also includes action ID, source finding, priority, status, evidence, and closure date.

The `source_id` field allows an audit nonconformity to trace to an action. Copying a finding into an action plan does not itself close the finding; verify effectiveness and record evidence.
