# Contributing

Contributions are welcome. Keep changes focused and suitable for small engineering teams.

1. Describe the problem and expected behavior.
2. Use fictional or anonymized data in examples; do not present invented results as real.
3. Add or update tests for behavior changes. Run `python -m pytest -q`.
4. Keep scripts readable, validate inputs, and return a non-zero status for invalid data.
5. Verify licenses before reusing external code, text, templates, or datasets. Add required attribution to `THIRD_PARTY_CREDITS.md`.
6. Clearly identify new functionality as IMPLEMENTED, EXAMPLE, PLANNED, or EXPERIMENTAL.

By contributing, you agree that your contributions are provided under the repository's MIT license.
