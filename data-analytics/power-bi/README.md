# Power BI integration

Power BI is optional. Import validated CSV output or source CSVs using a controlled refresh path. Suggested pages: Executive Overview, 5S, PDCA, FMEA, Inventory, Projects, and Document Control.

Suggested measures include 5S Score, Open Actions, Overdue Actions, High-Risk FMEA Items (using locally approved criteria), Inventory Availability, Document Compliance, Projects On Schedule, Average Resolution Time, and OEE. These are design suggestions; the repository does not implement every metric or a Power BI model.

See `data-dictionary.csv` for field descriptions and `automation/generate_kpis.py` for implemented metrics.
