# Academic reports

Use for laboratory work, undergraduate or extension projects, research, simulation/experimental studies and CAD/design projects. Start with the [academic template](../templates/academic-report-template.md); follow the specific institution, course, supervisor or publication requirements. No universal formatting standard is assumed.

## Recommended structure
Title → Authors → Institution → Course/project → Date → Abstract/summary → Objective → Background/theory → Materials and methods → Experimental setup → Procedures → Results → Analysis → Discussion → Conclusions → Limitations → References → Appendices.

For a simulation-only study, rename experimental setup to computational setup and explain why physical instrumentation is not applicable. Separate calculated or simulated results from measured validation data.

## Select supporting material
| Material | Include when it helps | What to record |
|---|---|---|
| Equations | Explain the model or calculation | Symbols, units, assumptions, source and applicability |
| Tables | Compare exact quantities/categories | Units, source, rounding and missing values |
| Graphs | Show trends, scatter or comparisons | Labeled axes/units, uncertainty where justified, dataset and processing |
| Photographs | Document setup or observations | Caption, date/context, authorship/permission |
| CAD and schematics | Explain geometry, assembly or interfaces | Revision, scale/units, reference frames, source and assumptions |
| Code | Reproduce a calculation | File/revision, environment and parameters; put long listings in appendices |
| Experimental data | Support observations | Raw data references, acquisition method, calibration and uncertainty |
