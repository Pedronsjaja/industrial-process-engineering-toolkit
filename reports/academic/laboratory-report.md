# Laboratory report

Use when a practical session tests a hypothesis or compares a model with observations.
Copy the [academic template](../templates/academic-report-template.md). For detailed measurements, attach a completed [test record](../templates/test-report-template.md).

1. State the objective and hypothesis before discussing the result.
2. Identify apparatus/instrument IDs, measurement range/resolution and calibration status where relevant.
3. Document setup, environmental conditions that affect the result, procedure, repetitions and deviations.
4. Reference raw readings and show processing equations with units.
5. Compare results to the hypothesis with uncertainty and limitations.
6. Distinguish a failed hypothesis, inconclusive evidence and an invalid test.

For example, a fictional beam-deflection exercise needs geometry, loading, support assumptions and displacement readings; it must not substitute invented measurements when data is absent.
Keep the report concise; put raw tables and code in appendices or linked datasets. Use [shared evidence rules](../README.md#data-and-results).
