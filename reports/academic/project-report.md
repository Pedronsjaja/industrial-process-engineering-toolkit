# Academic project report

Use for undergraduate, extension or CAD/design projects where the reader needs to understand choices and delivered scope.
Copy the [academic template](../templates/academic-report-template.md).

Record the problem, stakeholders, requirements, scope, alternatives, selection criteria, design revisions, implementation evidence and validation limits. Distinguish completed deliverables from planned work and identify each contributor's role.
For CAD, include units, assembly revision, design constraints and validation evidence; a render is not a structural test.

Link [5W2H actions](../../process-management/5w2h/README.md), [FMEA risks](../../quality/fmea/README.md) and [PDCA verification](../../process-management/pdca/README.md) only if used. In an extension project, separate activity records from evidence of outcomes.
Conclude against the stated objectives, not the amount of work performed; preserve attribution and a future-work section.
