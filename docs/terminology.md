# Terminology

| Term | Meaning in this toolkit |
|---|---|
| Action | Owned, time-bound response to a finding or improvement opportunity |
| Evidence | Verifiable observation, record, measurement, or reference supporting a claim |
| FMEA | Failure Modes and Effects Analysis; a structured risk-analysis method |
| KPI | Key Performance Indicator, interpreted with its definition and data quality |
| RPN | Risk Priority Number, calculated here as Severity × Occurrence × Detection |
| 5S | Sort, Set in order, Shine, Standardize, Sustain |
| PDCA | Plan, Do, Check, Act |
| 5W2H | What, Why, Where, When, Who, How, How much |

Use local, domain-appropriate definitions where terms have multiple accepted interpretations.
