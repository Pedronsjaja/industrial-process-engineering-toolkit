# Start Here

## What this toolkit does
Turn observations, risks and asset records into traceable actions, calculated indicators and reviewed engineering reports. You provide evidence and decisions; a few Python scripts validate CSVs and calculate summaries.

## Your first session
1. Open [Getting started](getting-started.md) for Python and CSV conventions.
2. Follow the [first improvement cycle](tutorials/first-improvement-cycle.md) using fictional data.
3. Compare generated outputs with the checked-in expected files.
4. Choose only the modules you need; copy their header-only templates to your own working directory.
5. Record your interpretation and verification plan in a [report template](../reports/README.md).

Commands run from the repository root, not from the automation folder. Use separate input/output names: output destinations can overwrite an existing file. Keep the source dataset unchanged.

## What you get, and what you decide
**Automated:** 5S averages, FMEA RPN/rank, supported KPIs, inventory checks, filename checks and local project folders.
**Manual:** observations, rating criteria, source links, risk acceptance, ownership, root-cause assessment, effectiveness verification, report writing and approval.
No automatic action creation, reminders, cloud permissions, PDF generation or academic formatting engine exists.

Use the [module map](module-workflow.md), [common workflows](common-workflows.md) or [documentation index](README.md) when you need a different route.
