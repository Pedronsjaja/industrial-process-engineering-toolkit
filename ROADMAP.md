# Roadmap

Items below are **PLANNED**, not implemented functionality. The current implemented scope is documented in the README.

## Near term

- Add richer CSV templates for PDCA, 5W2H, maintenance, project tracking, and OEE.
- Expand tests for malformed dates, encodings, and larger input files.
- Add optional Excel workbook generation with data validation.
- Add packaged Power BI dashboards and model samples.
- Add GitHub Actions CI for automated test runs.
- Add additional engineering templates and more fictional industrial case studies.
- Develop automated process mapping where a clear, testable use case exists.
- Explore automated OEE calculation after definitions and input data requirements are agreed.

## Later

- Explore repeatable import/export interfaces for common maintenance and inventory systems.
- Expand analytics, while documenting formula assumptions and data quality requirements.
- Add configurable scoring matrices for FMEA and 5S without prescribing universal thresholds.
- Add dashboard examples and documented refresh workflows.
- Gather practitioner feedback on terminology, accessibility, and localization.

## Principles

Keep the core dependency-light, preserve user ownership of operational data, cite external sources, and do not claim standards compliance or validated results without evidence.
