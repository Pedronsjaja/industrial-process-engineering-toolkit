# Examples

All records in this directory are **fictional examples** created solely to demonstrate CSV structure and script behavior. They do not represent real companies, assets, audit findings, risks, suppliers, or measured performance.

- `5s-workshop-case/`: sample audit and linked 5W2H actions.
- `inventory-case/`: fictional asset list.
- `engineering-project-case/`: sample FMEA register.

## Guided improvement cycle

Start with the [first improvement cycle](first-improvement-cycle/README.md) for linked fictional inputs, executed outputs and a manually authored review report. Follow the [tutorial](../docs/tutorials/first-improvement-cycle.md) to reproduce and interpret the results.
