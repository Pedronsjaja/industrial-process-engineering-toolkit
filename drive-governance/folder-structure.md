# Recommended project folder structure

```text
PROJECT/
├── 00_Management/
├── 01_Requirements/
├── 02_Engineering/
├── 03_CAD/
├── 04_Electronics/
├── 05_Software/
├── 06_Testing/
├── 07_Data/
├── 08_Reports/
├── 09_Deliverables/
└── 99_Archive/
```

Generate locally with `python automation/generate_project_structure.py --root PROJECT`. For Google Drive, SharePoint, or OneDrive, map groups and inherited permissions to the provider's supported controls; do not assume a local folder layout configures cloud permissions.
