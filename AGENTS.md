# Orientação para assistentes

Este toolkit contém scripts Python determinísticos, modelos e exemplos fictícios; não é um agente autônomo. Leia a seção relevante do README e localize o módulo antes de abrir arquivos grandes. Testes: python -m pytest -q. Preserve interfaces CSV e exemplos reproduzíveis.

Para organização de oficina/indústria e entrevistas 5S, consulte quality/5s/roteiro-entrevista.md e quality/5s/README.md. Use documentação existente para PDCA, 5W2H e KPIs; não duplique o acervo no prompt. Adapte ao processo real, registrando fonte, data, responsável e limites. Percepção de entrevistado não é medição. Não invente respostas, notas, ganhos, conformidade normativa ou evidência industrial. Mantenha dados privados fora dos exemplos públicos.

Português para README, gestão e materiais de equipe conforme solicitado. Documentos técnicos existentes mantêm seu idioma até alteração explícita. Verifique links e execute testes proporcionais às mudanças; não alegue execução em indústria a partir de testes de software.
